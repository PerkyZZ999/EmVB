# @perkyzz/emvb-icons

The icon sets for the [EmVB](https://emvb.dev) editor's Icon library: Lucide, Font Awesome Free, Tabler and Remix Icon, as compact JSON. `@perkyzz/emvb` depends on an exact version of this package, so `npm i @perkyzz/emvb` installs it; you don't install or import it yourself.

Sets: Lucide 1.61.0 (ISC), Font Awesome Free 7.3.1 (icons CC BY 4.0), Tabler Icons 3.49.0 (MIT) and Remix Icon 4.8.0 (Apache-2.0), one JSON file each (`lucide.json`, `fontawesome.json`, `tabler.json`, `remix.json`).

Only the editor loads these files. When an editor picks an icon, its SVG is stored with the page, so public pages never load an icon set.
